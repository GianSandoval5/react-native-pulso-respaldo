# Registro de ideas y resultado

**2026-11-24 · America/Lima · React Native/Expo · Pulso de Respaldo.**

Siete días después del 17 de noviembre corresponde React Native. Antes de seleccionar el tema se revisaron Despensa Clara, Repara Cerca, Lectura Viva, Presta Cerca, Turno Solidario y Minuto de Escena. Ninguno cubre planificación doméstica de energía.

La idea elegida es un cuaderno para comparar una batería con una carga priorizada. Se descartó controlar hardware, pronosticar tarifas o recomendar conexiones eléctricas. El alcance final contiene cinco pantallas, cálculo local auditable, CRUD de planes y un historial de simulacros.

Referencias del problema y compatibilidad:

- [Ready.gov · guía de preparación](https://www.ready.gov/sites/default/files/2021-11/are-you-ready-guide.pdf): recomienda inventariar los equipos que dependen de electricidad y preparar alternativas.
- [Department of Energy · medición de potencia en espera](https://www.energy.gov/cmei/femp/measuring-standby-power): distingue potencia instantánea y consumo de energía a lo largo del tiempo.
- [Expo SDK reference](https://docs.expo.dev/versions/latest/): matriz oficial de Expo, React Native, React y plataformas.
- [FTW](https://github.com/srcfl/ftw): proyecto público local-first de gestión energética consultado para comprender el espacio del problema.
- [MobileLab Data API](https://github.com/GianSandoval5/MobileLab/blob/master/docs/data-api.md): contrato de persistencia local.

El diseño visual, los flujos, el dominio, el DTO y las pruebas son originales. No se copió código ni interfaz de las referencias.
